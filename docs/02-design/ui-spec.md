# DES-003 界面规范

这份文档回答一个问题：**有哪几屏、每屏放什么、点下去发生什么。**

它约束的是"结构与行为"，不约束像素级视觉；配色与字体在实现期用设计令牌统一，不在本文展开。

## 1. 目标与非目标

| 项 | 内容 |
|---|---|
| 本文件解决 | 页面清单、布局骨架、组件规则、交互与文案约束 |
| 本文件不解决 | 接口形状（`DES-002`）、视觉稿、动效细节 |

## 2. 页面清单

| 路由 | 页面 | 主要读者 | 是否只读 | 首屏数据 |
|---|---|---|---|---|
| `/login` | 登录 | 所有人 | — | — |
| `/register` | 邀请码注册 | 受邀者 | — | — |
| `/password` | 改密 | 所有人 | — | — |
| `/` | 概览 | viewer / editor / admin | 否 | 5 个统计标量 + 30 天趋势 + 预警前 5 条 |
| `/materials` | 物料列表 | 全部 | 否 | 分页列表（含缩略图） |
| `/materials/new` | 兼容地址 | admin、editor | — | 重定向到 `/materials?new=1`，在列表页弹出建档窗口 |
| `/materials/:id` | 物料详情 / 编辑 | 全部（只读账号仅查看） | 视角色 | 单条详情 |
| `/movements` | 流水列表 | 全部 | 否 | 分页列表 |
| `/movements/new` | 兼容地址 | admin、editor | — | 重定向到 `/movements?new=1`，在列表页弹出登记窗口 |
| `/stats` | 统计详情 | admin | 是 | 分类分布 + 出库 Top10 |
| `/admin/users` | 账号管理 | admin | 否 | 用户列表 |
| `/admin/invites` | 邀请码 | admin | 否 | 邀请码列表 |

`viewer` 只读：不出现"建档""登记""红冲"按钮，直接隐藏而非置灰——置灰会让只读角色反复点击试探。

**新建与登记采用列表页弹窗**（2026-11-03 调整）：建档与登记都是"看列表 → 填一条 → 回列表"的短动作，
独立成页会让用户丢失筛选与滚动位置。弹窗状态放在查询串（`?new=1`），关闭即移除，浏览器后退可自然关闭；
旧地址 `/materials/new`、`/movements/new` 保留为兼容入口，只读账号直连仍得到 403。

## 3. 布局骨架

```
┌─────────────────────────────────────────┐
│ 顶栏：产品名 · 当前账号 · 退出          │
├──────────┬──────────────────────────────┤
│ 侧栏     │ 内容区                       │
│ 概览     │ 页标题 + 主操作按钮（右上）   │
│ 物料     │ 筛选条                       │
│ 流水     │ 主体（表格/表单/图表）        │
│ 统计     │ 分页                         │
│ 管理 ▾   │                              │
└──────────┴──────────────────────────────┘
```

- 侧栏宽度固定 200px，可折叠为图标（宽度 <1024px 时自动折叠）。
- 主操作按钮固定在页标题右侧，一页最多一个主按钮。
- 筛选条在表格上方，参数变化后立即查询，不需要"搜索"按钮；输入框 400ms 防抖。

## 4. 组件规则

### 4.1 表格

| 规则 | 说明 |
|---|---|
| 列宽 | 金额/数量列右对齐并等宽数字字体；文本列左对齐 |
| 空值 | 显示 `—`，不显示空白或 `null` |
| 排序 | 可排序列头带箭头；默认按 `updatedAt` 降序 |
| 分页 | 底部分页器，显示"第 X/Y 页，共 N 条"；每页 20 条，可切换 50/100 |
| 空状态 | 文案 + 主操作按钮，如"还没有物料，先建一条" |
| 加载 | 骨架屏，不用转圈遮罩 |
| 缩略图 | 物料列表在名称后显示 40×40 缩略图；无图显示 `—`；点击可预览 |
| 长文本 | 物料名在 170px 列宽内换行，不截断、不撑破列宽 |
| 移动端 | 横向滚动，首列（名称）吸附，操作列固定右侧 |

### 4.2 表单

- 必填项在标签后加红色 `*`；错误提示显示在字段下方，不弹 toast。
- 提交按钮在请求期间禁用并显示"保存中…"，防重复提交。
- 离开有未保存改动时二次确认。
- 数量输入框只接受数字与小数点，失焦后格式化为 3 位小数。

### 4.3 状态与徽标

| 语义 | 颜色倾向 | 出现位置 |
|---|---|---|
| 正常 / active | 绿 | 物料状态、账号状态 |
| 停用 / inactive | 灰 | 同上 |
| 预警（零库存、负库存） | 红 | 概览、列表行 |
| 低于安全线 | 橙 | 同上 |
| 呆滞 | 蓝灰 | 同上 |

同一物料命中多条预警时只显示最高严重度徽标（与 `DES-004` M-9 一致）。

### 4.4 图表

- 趋势图：折线，X 轴固定 30 天，缺失日为 0（`DES-004` M-5 已保证补齐）。
- 分类分布：横向条形，按种类数降序，**不显示饼图**——类别超过 5 个时饼图不可读。
- 图表必须提供"查看数据表"切换，纯图形不构成唯一信息载体（§4.5 约束 6 的延伸）。

## 5. 交互规则

| 场景 | 规则 |
|---|---|
| 红冲 | 二次确认弹窗，必须填写原因；确认按钮文案"确认红冲"，不用"确定" |
| 删除物料 | 二次确认；若被拒绝（422），提示改为"该物料已有流水，不能删除，可改为停用" |
| 权限不足 | 页面级 403 展示"你没有这个权限"，并给返回概览的链接；不暴露资源是否存在 |
| 会话过期 | 任意请求返回 401 时跳登录页，登录后回原页 |
| 须改密 | `must_change_password` 为真时，除改密页外全部重定向到 `/password` |
| 导出 | 物料列表页头的「导出」按钮携带当前筛选条件（关键词、分类、库存状态、状态）下载 CSV；超过 50000 行返回 422，提示缩小筛选范围 |
| 导入 | 物料列表页头的「导入」按钮：上传 CSV，服务端整批校验，弹窗展示「共 N 行 / 成功 / 失败」与逐行错误（行号、字段、原因）；任一行有错则整批不写入 |
| 批量操作 | MVP 不做批量操作（不在范围） |

## 6. 文案与术语

- 界面文案只能使用 `docs/00-glossary.md` 中状态为 `active` 的中文词条（G-4）。
- 禁用写法不得出现在按钮、表头、提示语中。
- 按钮用动词原形（"保存""登记""红冲"），不用"提交表单""点击这里"。
- 错误提示给"发生了什么 + 怎么办"，不写"操作失败"这类无信息量文案。

## 7. 响应式与移动端

| 断点 | 行为 |
|---|---|
| ≥1280px | 完整布局，侧栏展开 |
| 1024–1279px | 侧栏折叠为图标 |
| <1024px | 侧栏收起为抽屉；表格横向滚动；操作列固定 |

移动端为**只读视图**（NFR-001 要求）：可查看概览、物料、流水、统计，不提供建档与登记。移动端不隐藏筛选，但默认收起为"筛选"按钮。

## 8. 可访问性与性能

| 项 | 要求 |
|---|---|
| 键盘 | 所有操作可用 Tab 到达，弹窗内焦点锁定并在关闭后归还 |
| 对比度 | 正文对比度 ≥4.5:1，不依赖颜色单独传达预警（同时给文字徽标） |
| 首屏 | 概览首屏 3 秒内呈现分类汇总与预警清单（GOV-000 §5.4 F3） |
| 空数据 | 首屏无数据时展示引导，不展示 0 值大屏 |
