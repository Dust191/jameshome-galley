### 3.2 遇到的问题与处理

| 编号 | 问题 | 处理 |
|---|---|---|
| P-1 | M-8 若按原文"四项齐全"实现，因分类与单位是 `NOT NULL`，指标将恒为 100% | 按 Q-2 A 改为两项判据；并在文中注明"0 视为未设置"，否则 `safety_stock` 默认值 0 会让判据恒真 |
| P-2 | 接口文档最容易与规范分叉：状态码、分页、错误体若各写一套，实现期两处打架 | 逐条引用 GOV-000 §5.5，只在规范未覆盖处补充（CSRF、幂等键、数量用字符串传输） |
| P-3 | 数量用字符串传输与"前端排序/统计"直觉冲突 | 明确取舍：`numeric(14,3)` 超过 JS 安全整数范围的风险虽小，但浮点比较更常见；前端只做展示不做运算，故用字符串 |
| P-4 | DES-001 已 `approved`，但本轮改动了它的引用关系（新增 DES-002/003 指向它） | 只新增反向引用（DES-002 的 `related` 里含 DES-001），不回改已审定的正文 |
