## 三、改动

| 文件 | 内容 |
|---|---|
| `backend/Dockerfile` | 多阶段：`eclipse-temurin:25-jdk-alpine` 构建，`25-jre-alpine` 运行；装 curl 供健康检查；非特权账号；`MaxRAMPercentage=55`，OOM 直接退出 |
| `backend/.dockerignore` | 排除 `target/`、`.git/` 等 |

| `.github/workflows/release.yml` | 打 `v*` tag 触发；矩阵构建 api/web；推 `ghcr.io/<owner>/galley-api|galley-web`；tag 用 semver 归一（`v0.1.0` → `0.1.0`） |
| `compose.prod.yml` | api 默认镜像改为 `ghcr.io/dust191/galley-*:0.1.0`；健康检查由 `wget` 改为 `curl`（运行层装的是 curl） |

## 四、验证

| 项 | 结果 |
|---|---|
| OSS 桶存在且私有 | 公网 403、内网 403 |
| compose 与 release.yml 的 YAML 解析 | 通过 |
| 基础镜像可用 | `eclipse-temurin:25-jdk-alpine` / `25-jre-alpine` 经代理拉取成功 |
| `nginx.conf` 语法 | `nginx -t` 通过 |
| jar 名匹配 | `target/galley-0.1.0.jar` 命中 `galley-*.jar` |
| 后端镜像完整构建 | **受阻**：BuildKit 解析基础镜像时不走 dockerd 代理；容器内 Maven 也不读 `HTTP_PROXY`。本地网络环境下无法完成，交由 CI 首次 tag 验证 |
| 前端镜像完整构建 | 未单独跑；CI 的 `pnpm build` 已验证构建步骤 |

**由此改了一处**：Dockerfile 首行的 `# syntax=docker/dockerfile:1` 已删除——该指令会让 BuildKit 去 Docker Hub 取前端镜像，在受限网络下直接卡住；本文件未用到需要外部前端的特性。
