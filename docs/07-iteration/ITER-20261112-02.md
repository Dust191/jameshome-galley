## 二、改动

### 2.1 签名 URL（Issue #52 / `DVT-12`）

| 项 | 改动 |
|---|---|
| 接口 | `ObjectStorage.publicUrl(key)` → `signedUrl(key)`；javadoc 写明桶私有读、地址即凭据 |
| 实现 | `MinioObjectStorage` 增加 `signer` 客户端，用 `getPresignedObjectUrl` 生成 GET 地址 |
| 双 endpoint | `endpoint` 供后端读写（生产为内网），`publicEndpoint` 只用于签名（生产为公网）；缺失时等于前者（开发 MinIO） |
| 区域 | 新增 `region` 并显式传给客户端，避免签名前触发 `GetBucketLocation` |
| 有效期 | `signed-url-ttl-seconds` 默认 3600，上限 604800 |
| 调用点 | 文件上传返回的 `url`、物料详情的 `imageUrl` |
| 配置 | `.env.example` 移除 `GALLEY_S3_PUBLIC_BASE`，新增 `GALLEY_S3_PUBLIC_ENDPOINT`、`GALLEY_S3_REGION`、`GALLEY_S3_SIGNED_URL_TTL_SECONDS` |

**为什么必须两个 endpoint**：后端读写走内网省流量，但签名会把这个 host 写进地址；若用内网地址签名，浏览器解析不了，图片仍然 404。签名本身不发网络请求，所以多一个客户端没有运行成本。

### 2.2 生产编排（`compose.prod.yml`）

- 五个服务：`api` / `web` / `caddy` / `cloudflared` / `db`；
- `db` 用 `postgres:18.3-alpine`，数据卷挂 `/var/lib/postgresql`（18 起的新路径），带 `pg_isready` 健康检查；
- `api` 等 `db` 健康后再启动；`caddy` 等 `api` / `web` 健康；
- `cloudflared` 用 `TUNNEL_TOKEN` 环境变量，不把 token 放命令行；
- 统一 `json-file` 日志并限制 20 MB × 5，避免写满 40 GB 系统盘；
- 镜像 tag 默认值由 `0.0.1` 改为 `0.1.0`，与 `pom.xml` 对齐；caddy 与 cloudflared 走变量，后者缺失时编排直接报错。

### 2.3 反向代理（`infra/caddy/Caddyfile`）

- 从 `:443` + `{$ACME_EMAIL}` 改为内网 `:80`，关闭自动 HTTPS 与管理端点；
- 补 `Content-Security-Policy`（`img-src` 放行 `https://*.aliyuncs.com`），补 JSON 访问日志；
- `/actuator/*` 收敛为 `/actuator/health*`，其余端点不对外。
