## 四、被抓出的三个编排缺陷

| 缺陷 | 表现 | 修正 |
|---|---|---|
| 变量默认值写成 `${VAR:default}` | `docker compose config` 直接报 invalid interpolation | 改为 `${VAR:-default}`；同时把 api/web 的默认 tag 从 0.1.0 对齐到 0.2.0 |
| 健康检查用 `localhost` | 容器内先解析到 `::1`，nginx 只监听 IPv4，web 一直 unhealthy | 全部改 `127.0.0.1` |
| db 健康检查引用 `GALLEY_DB_USERNAME` | 容器里只有 `POSTGRES_USER`，变量展开为空，`pg_isready` 参数错位 | 改用 `$${POSTGRES_USER}` / `$${POSTGRES_DB}` |

**根因共性**：CI 只做 lint / 测试 / 构建，**从不解析 compose**，这三类错只有在真机上 `compose config` 或启动时才暴露。后续应把 `docker compose config` 加进 CI（需要一份占位 env）。
