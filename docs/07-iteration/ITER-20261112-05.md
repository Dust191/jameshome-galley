## 三、签名地址实测

用真实桶跑了一次「上传 → 签名 → 直接 GET → 删除」，临时测试类用完即删、未入库：

```
SIGNED_HOST=jameshome-galley.oss-cn-hangzhou.aliyuncs.com
STATUS=200
```

结论：MinIO SDK 的 V4 预签名在 OSS 标准 endpoint 上可用，**不再需要 S3 兼容域名**；后端读写仍走内网 endpoint，签名走公网 endpoint，两条路互不干扰。
