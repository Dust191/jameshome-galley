## 三、变更过程

### 3.1 执行步骤

1. 确认时间与仓库状态：跨天，工作区干净，`main` 停在 `8bb24d5`（v0.0.2）。
2. 按 Q-1 改写 G3 的 UAT-4，并在 GOV-000 附录 F 记一行修订依据——这是**改已审定的验收标准**，必须留痕。
3. 按 Q-3 落 ADR-0005：业务只依赖 `ObjectStorage` 四方法，`publicUrl(key)` 由实现决定，业务不得拼 URL。
4. 把 `V1__init_schema.sql` 传到虚拟机，在 `postgres:18.3` 容器里 `psql -v ON_ERROR_STOP=1` 重放。
5. 用一段带 `DO $$ ... EXCEPTION` 的脚本逐条验证不变式，全部通过（§3.3）。
6. 按 Q-2 起 MinIO，建桶 `galley-material`。

### 3.2 遇到的问题与处理

| 编号 | 问题 | 处理 |
|---|---|---|
| P-1 | 虚拟机 `ping` 不通 | 用户已启动；SSH 可连，说明是 ICMP 被拦而非主机离线 |
| P-2 | `docker pull minio/minio` 报 403：默认镜像源 `docker.m.daocloud.io` 拒绝该仓库 | 试过 `quay.io`（401，已停止匿名拉取）与 `dl.min.io` 二进制（410，已下架）；最终用华为镜像站 `swr.cn-north-4.myhuaweicloud.com/ddn-k8s/docker.io/minio/minio:latest` 拉取成功 |
| P-3 | 想让 Docker 直连 Docker Hub 需改 `daemon.json` 并重启，但 `sudo` 需要密码 | **未强行改**：改用镜像站绕过，把这条写进 `DEV-001` 常见问题与 `ADR-0005`，根治方案留给用户在方便时执行（清掉失效的 `registry-mirrors`） |
| P-4 | `material_category` 的联合唯一因 `parent_id` 可为空而失效（NULL 互不相等） | 建 `coalesce(parent_id, 零值 UUID)` 表达式唯一索引 |

### 3.3 迁移验证结果（真实 PostgreSQL 18.3）

`psql -v ON_ERROR_STOP=1` 重放成功：8 表、10 索引、2 函数、2 触发器全部创建。

四条不变式逐条验证，全部符合 `DES-001`：

| 验证 | 操作 | 结果 |
|---|---|---|
| I-1 流水不可改 | `UPDATE stock_movement SET quantity = -6` | 拒绝：“数量/类型/物料/发生时间不可修改，修正须走红冲” |
| I-2 流水不可删 | `DELETE FROM stock_movement` | 拒绝：“流水不可删除” |
| I-4 红冲符号 | 对 `OUT -5` 插入 `REVERSAL -5` | 拒绝：“红冲数量 -5.000 必须等于原流水相反数 5.000” |
| I-3 一次红冲 | 同一原流水插入第二条红冲 | 拒绝：违反唯一约束 `uq_movement_reversal_of` |

正确红冲后求和：`-5 + 5 = 0`，与 `DES-001` §4.1 的结存恒等式一致。
