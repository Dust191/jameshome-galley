## 三、由 A-1 ~ A-4 推出的事实

1. **入站路径变了**：原来计划「用户 → 443 → Caddy」，现在「用户 → Cloudflare 边缘 → Tunnel → 本机 `cloudflared` → Caddy」。Caddy 不再持有证书，ACME 相关配置作废，TLS 由 Cloudflare 终结；Caddy 继续负责安全头与路径分流。
2. **安全组更简单**：只需放行 22（限固定源 IP）；80 / 443 保持关闭，减少暴露面。出站需允许 `cloudflared` 连接 Cloudflare 边缘（443）。
3. **数据库责任转移**：没有托管备份与高可用，备份、恢复、版本升级、磁盘增长全部由本项目承担；`RUN-002` 的脚本从「可选」变成「唯一手段」。
4. **RPO 达不到 §7.4 的 ≤5 分钟**：每日全量的现实上限是 24 小时，除非启用 WAL 归档。已按 `DVT-11` 登记。
5. **OSS 访问模型存在未决冲突**：现有实现用 `publicUrl` 拼公网地址下发图片（`ADR-0005`，2026-11-10 裁定「以实现为准」）；若 bucket 按规范设为私有读，图片会 403。二者只能选一，见 §五 L-02。
