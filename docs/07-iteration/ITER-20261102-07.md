## 三、变更过程

### 3.1 执行步骤

1. 复用物料列表的查询（`MaterialMapper.search`），保证导出与列表的筛选语义完全一致——两套查询迟早会分叉。
2. 一次多取一行（`MAX_ROWS + 1`）：取到 50001 行就说明超限，不必再跑一次 count。
3. 先拼字符串再整体加 BOM，避免多次数组拷贝。

### 3.2 遇到的问题与处理

| 编号 | 问题 | 处理 |
|---|---|---|
| P-1 | 无 | 本项实现顺利，未遇到阻塞 |

### 3.3 验证手段与结果

| 验证 | 结果 |
|---|---|
| 导出响应 | HTTP 200，208 字节 |
| 前 3 字节 | `ef bb bf`（UTF-8 BOM，UAT-12） |
| 内容 | 表头 + 大米（结存 77.000）+ 面粉（结存 0） |
| 数量格式 | `10.000` / `77.000`，三位小数由 `numeric(14,3)` 原样带出，未经浮点 |

## 六、与上轮的差异摘要

上轮能看统计，本轮能把数据带走。BOM 这个细节看似琐碎，但少了它，
用户第一次用 Excel 打开就是一片乱码——这类"第一次体验"的问题，修起来只要三行，被投诉起来却很久。
