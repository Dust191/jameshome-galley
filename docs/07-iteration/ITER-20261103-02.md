## 三、未实施项与理由

**概览口径（原第 3 项）**：开发者要求"负库存并入缺货、待补货不含缺货"，使两卡不重叠、卡片合计等于预警清单条数。

该要求与既有口径冲突，已按约定停下提问：

| 冲突点 | 原文 |
|---|---|
| `DES-004` M-2 | 低库存 = `quantity < safety_stock`，明确"`safety_stock = 0` 且 `quantity < 0` 时计入" |
| `DES-004` M-3 | 零库存 = `quantity = 0`，明确"不含负库存，负库存单列在 M-9 最高档" |
| 既往裁定 | `ITER-20261102-06` 的 L-03，开发者答"维持现状即可"（允许两卡重叠） |

开发者本轮答复：**"以既有口径为准，不改动"**。故本轮未修改任何指标口径、卡片文案与 tooltip，概览仍显示"待补货 3 / 缺货 5"，预警清单 5 条。二者差异属已知且经裁定保留的现象。
