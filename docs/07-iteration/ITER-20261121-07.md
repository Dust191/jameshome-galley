## 三、变更过程

### 3.1 做法

**O-5 分三步取真实证据**：

1. 把 api 日志落到宿主目录（`LOGGING_FILE_NAME` + 绑定卷），并给 staging 单独目录，避免两套混写；
2. 把 `GALLEY_RECONCILE_CRON` 临时改成 `0 */5 * * * *`，重建 api，等真实调度触发；
3. 19:20:00 捕获到「结存对账通过」写入 `/opt/galley/logs/api.log` 后，把 cron 改回 `0 30 2 * * *` 并再重建一次。

**F-4**：在 staging 建一个 viewer 账号，用 Playwright 以 390×844 移动视口登录，数页面上的写操作按钮，并截图留档。

**S-6**：按 OWASP Top 10（2021）十条逐项对照代码与实测，写成 `GOV-008`，缺口单列并给出排期。

### 3.2 遇到的问题与处理

| 编号 | 问题 | 处理 |
|---|---|---|
| P-1 | 登录页输入框没有 `name` 属性，`input[name=username]` 选不中 | 改用 `#username` / `#password` |
| P-2 | 提交按钮文案是「登 录」（中间有空格），按 `/登录/` 匹配不到 | 改为在密码框回车提交 |
