### 3.2 第三方许可清单的做法

不引第三方工具，两步生成：后端 `dependency:list -DincludeScope=runtime` 拿 120 个制品，
逐个读本地 Maven 仓库 POM 的 `<licenses>` 节（父 POM 向上追溯 2 层）；前端 `pnpm licenses list --prod --json` 拿 78 个包。

五处需要人工判断的地方写进 GOV-005 §3：jsqlparser 双许可取 Apache-2.0、
spring-session 的 POM 把许可字段写成了 Broadcom 占位（实际仍是 Apache-2.0）、
bcprov 的 POM 没有 licenses 节（随包 LICENSE 为 MIT 风格）、jakarta 两个 API 是 EDL 1.0（BSD-3 风格）、HdrHistogram 是 CC0。

结论：**0.1.0 基线无 copyleft 传染风险**，除 jsqlparser 需按双许可选择 Apache 选项外，其余全部直接符合或宽于允许清单。

### 3.3 顺手修掉的一个 CI 阻断

`backend/mvnw` 在 git 里是 644。本机永远发现不了——Windows 不检查执行位；
但 GitHub Runner 是 Linux，`./mvnw` 会直接 Permission denied，**首次 PR 的 CI 必挂**。
已 `git update-index --chmod=+x` 修正。
