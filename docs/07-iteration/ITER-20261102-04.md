## 三、变更过程

### 3.1 执行步骤

1. 起数据库容器（`compose.dev.yml`），确认空库，用 SSH 本地转发把 5432 映到本机 15432（本机 5432 已被占用）。
2. 启动应用让 Flyway 跑迁移——这一步暴露了第一个问题（见 P-1），修完后 V1、V2 成功应用。
3. 引导管理员自动创建，一次性口令打印在日志；据此验证登录、会话、CSRF、改密拦截、改密后权限刷新。
4. 建分类与单位，验证字典表的重名与占用校验。
5. 写存储抽象与 MinIO 实现，上传图片，再建档带上图片 key，验证 `imageUrl` 正确回填且浏览器可访问。
6. 按 UAT-2 逐条验证字段级错误；按 UAT-7 验证停用后默认隐藏；按 UAT-10 验证 viewer 只能读。
7. 补三个测试类，`mvn test` 28 个用例全绿。

### 3.2 遇到的问题与处理

| 编号 | 问题 | 处理 |
|---|---|---|
| P-1 | `flyway-core` 在依赖里，但**迁移一条都没执行**，应用直接报 `relation "app_user" does not exist` | Spring Boot 4 把自动配置按技术拆成独立模块，只有 `flyway-core` 时不会装配迁移器、也不报错。改为 `spring-boot-starter-flyway` |
| P-2 | 引导管理员插入失败：`Type handler was null ... javaType (java.util.UUID)` | MyBatis 3.5.19 **没有**内置 `UUIDTypeHandler`。自写 `UuidTypeHandler` 并注册三种 jdbcType |
| P-3 | 启动报 `Port 5324 was already in use`，而 `application.yml` 写的是 8080 | 运行环境注入了 `GALLEY_SERVER_PORT=5324`，优先级高于配置文件。命令行参数 `--server.port` 优先级最高，用它覆盖；并写入 `DEV-001` 常见问题 |
| P-4 | `PATCH {"status":"inactive"}` 返回 500 | Jackson 默认按枚举常量名精确匹配，`inactive` 不认 `INACTIVE`。开 `accept-case-insensitive-enums`；同时发现此类错误被当成 500，补 `HttpMessageNotReadableException` → 400 |
| P-5 | 上传成功但图片 URL 返回 403 | MinIO 桶默认私有。`mc anonymous set download`，并写进 `DEV-001` |
| P-6 | `DES-002` 没有图片上传端点，但 UAT-1 要求「新建物料（含图片）」 | 补 `POST /api/v1/files`，返回 `{key, url}`；`image_url` 仍只存 key（`ADR-0005`） |
| P-7 | 原安全配置把 `/materials/**` 整体给 admin+editor，viewer 连列表都读不到 | 按 HTTP 方法拆分：GET 对全部已登录角色开放，写方法按角色收；顺带修正单位（GET 全员、写 admin）与物料删除（admin） |

### 3.3 验证手段与结果

第一次在真实 PostgreSQL 18.3 上把 HTTP 链路走完，逐项实测：

| 验证 | 结果 |
|---|---|
| Flyway 迁移 | `Successfully applied 2 migrations`，now at v2 |
| 引导管理员 | 创建成功，口令一次性打印，`mustChangePassword=true` |
| 未登录访问 `/auth/me` | 401 `AUTH_REQUIRED` |
| 登录 → 改密前访问业务接口 | 403 `PASSWORD_CHANGE_REQUIRED` |
| 改密 | 204，`mustChangePassword` 变为 false，权限即时刷新 |
| 建分类 / 建单位 / 重名 | 201 / 201 / 409 `DUPLICATE_KEY`（`field=name`） |
| 上传图片 | 201，key 形如 `material/2026/11/<uuidv7>.png`，URL 实测 200 |
| 建物料（含图片） | 201，`imageUrl` 正确回填，`currentStock=0` |
| 三位小数 / 负安全库存 / 缺必填 | 400，`field` 分别为 `safetyStock`、`safetyStock`、`name` |
| active 直跳 archived | 422 `INVALID_STATUS_TRANSITION` |
| active → inactive | 200，`version` 0→1 |
| 停用后列表默认隐藏 / `status=all` | total 0 / total 1 |
| 旧 version 再次提交 | 409 `VERSION_CONFLICT` |
| 软删无流水物料 / 删后详情 | 204 / 404 |
| 删有物料的分类 | 422 `CATEGORY_IN_USE`，回报占用 1 种 |
| viewer 读物料 / 写物料 / 读账号 | 200 / 403 / 403 |
| `mvn test` | 28 个用例通过，4 条 ArchUnit 全绿 |

**尚未验证**：有流水的物料软删（需 T4）、并发写、前端页面。
