# RUN-004 上线检查单

这份文档回答一个问题：**G5 的 27 条判据里，哪一条已经拿到证据、哪一条还没有。**

## 1. 用法

- 每条只有两种结果：**已通过**或**未通过**。没有「基本通过」。
- 证据必须可复核：命令输出、文件路径、页面地址、日志行。不写「已确认」「已检查」。
- 标 ★ 的条目是一票否决项，未通过时整门不通过，其余条目的结论不必再讨论。
- 条目通过后不删行；判据本身变了，改文字并在 §5 记一笔。
- 单人期由开发者一行签字；有多人后按 `DEV-008` §5 走评审，检查单随 PR 一并提交。

## 2. 27 条判据

六组与 `DEV-009` §7.6 逐条对应。改一处必须改两处，否则以本节为准回改 `DEV-009`。
