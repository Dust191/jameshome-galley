# GLOSSARY-001 总名词解释

这份文档回答一个问题：**每个词在本项目里只有一个意思，它是哪个意思。**
状态说明：全部 34 条词条已于 2026-10-31 由开发者确认，状态由 `proposed` 转为 `active`（G-5）。自此，文档、代码标识符、界面文案只能使用本表 `active` 词条。

## 1. 使用规则

| 编号 | 规则 |
|---|---|
| G-1 | 一个概念只有一个正式词条；其他写法登记为「禁用写法」，不得出现在文档、代码与界面中 |
| G-2 | 定义中不得引用未登记词条 |
| G-3 | 代码标识符（表名、类名、接口路径、字段名）必须与英文名一致 |
| G-4 | 界面文案必须使用中文词条，不得使用禁用写法 |
| G-5 | 新增词条由模型提出 `proposed`，开发者确认后转 `active`，模型不得自行置为 `active` |
| G-6 | 词条修订属全局口径变更，须走 RFC 并在末尾记录变更历史 |
| G-7 | 作废词条不得删除，状态改为 `deprecated` 并注明替代词条 |
