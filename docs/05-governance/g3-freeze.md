## 4. 冻结内容与规则

**进入 0.1.0 的能力**：认证（邀请码注册 / 登录 / 改密）、物料建档与图片、流水登记与冲正、结存与预警、
九项统计、物料与流水 CSV 导出、物料导入、结存对账、前端 11 个路由。

| 场景 | 冻结后是否允许 |
|---|---|
| P0 / P1 缺陷修复 | 允许，走补丁版本 `0.1.x`，`CHANGELOG` 记入「修复」 |
| 新功能、接口新增或改语义 | 不允许，进入 0.2.0 或「参考方向」 |
| 数据库迁移 | 只前滚；按 `DEV-002` §6 先加后删，禁止同版本内破坏性变更 |
| 依赖升级 | 仅安全修复类，且需重跑 osv-scanner 与全量测试 |
| 文档更正 | 允许；已发布版本的 `CHANGELOG` 条目不得回改 |

现有三个迁移（`V1__init_schema.sql`、`V2__spring_session.sql`、`V3__movement_idempotency.sql`）均为
增量式，无删列与改类型，回退只需回退代码、保留表结构。
