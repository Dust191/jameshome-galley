# GOV-008 安全自查表

这份文档回答一个问题：**按 OWASP Top 10（2021）逐条对照，这套系统哪些防住了、哪些还有缺口。**

## 1. 怎么读

- **已确认**：有代码或实测证据，证据列写得出位置。
- **部分**：主体成立，但有明确缺口，缺口单列在 §3。
- **未覆盖**：没有对应措施，必须在上线前处理。

本表由模型起草，2026-11-21 经开发者签字生效。复核时点与 `RUN-004` 同步。

## 2. 逐条对照

| 编号 | OWASP 项 | 结论 | 证据 |
|---|---|---|---|
| A01 | 越权访问 | 已确认 | 三角色矩阵由 `PermissionMatrixTest` 6 条覆盖：匿名一律 401、viewer 可读不可写且管理接口 403、editor 不能管单位与账号、admin 全放行 |
| A02 | 加密失效 | 部分 | 口令用 `BCryptPasswordEncoder` 存哈希，不存明文；对外 TLS 由 Cloudflare 终结，源站不接受公网入站；**缺口：数据库备份为明文 dump**，只靠私有桶与签名访问保护 |
| A03 | 注入 | 已确认 | 数据访问走 MyBatis 参数绑定，未见字符串拼接 SQL；CSV 导入按列校验并拒绝多余列；导出走固定查询 |
| A04 | 不安全设计 | 部分 | 首登强制改密、流水幂等键、冲正不可重复、停用分类不可删；**缺口：未做正式威胁建模**，权限边界只按角色而非数据范围 |
| A05 | 安全配置错误 | 已确认 | 无固定初始口令（空库首启随机生成并只打印一次）；密钥只存 `.env.prod`（600），不入库；Caddy 配 HSTS、CSP、X-Content-Type-Options、Referrer-Policy；错误响应只回 `traceId`，不带堆栈 |
| A06 | 易受攻击组件 | 已确认 | Dependabot 每周扫描；当前 3 条 moderate、0 High/Critical；镜像基于 alpine 精简运行时 |
| A07 | 认证与会话失效 | 部分 | CSRF 走 Cookie 模式并校验 `X-XSRF-TOKEN`；会话 Cookie 默认 HttpOnly；**缺口：SameSite 与 Secure 未显式声明**，依赖容器与反代默认 |
| A08 | 软件与数据完整性 | 部分 | 图片走签名地址、默认 1 小时过期，桶私有；备份导出带 sha256 并在 OSS 侧回查 MD5；审计日志与业务写同事务；**缺口：备份文件本身未加密、未签名** |
| A09 | 日志与监控失效 | 部分 | 审计表记录登录、改密与关键写操作；应用日志已落盘到宿主目录；**缺口：业务层告警暂缓（`O-2`），异常只能靠人看** |
| A10 | 服务端请求伪造 | 已确认 | 服务端不抓取用户提供的 URL；对外只连固定的 OSS endpoint 与 OIDC 无关服务；图片地址由服务端签名生成 |

合计：已确认 6 项，部分 4 项，未覆盖 0 项。

## 3. 缺口清单

| 编号 | 缺口 | 影响 | 处置 |
|---|---|---|---|
| G-1 | 备份为明文 dump | 拿到备份即可读全部业务数据与口令哈希 | 迁移到 OSS 服务端加密或本地 `age` 加密后再上传；列入 S6 |
| G-2 | 会话 Cookie 未显式声明 `SameSite` / `Secure` | 依赖运行时默认值，换容器可能变化 | 在 `application.yml` 显式配置，随下一版发布 |
| G-3 | 未做威胁建模 | 权限只按角色，未按数据范围 | 在 S6 补一次；当前单团体场景风险可控 |
| G-4 | 业务告警暂缓 | 入侵或异常不一定被及时发现 | 随 `O-2` 解除 |

以上四条都不阻塞 G5：G-1 与 G-3 已排入 S6，G-2 随下次发版，G-4 已有明确解除条件。
